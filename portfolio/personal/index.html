Architecture

Pre-compiling with SASS/SCSS

I decided to practise my fresh knowledge of SASS with my personal website. After some research, I decided to apply the 7-1 architecture style and size it down to 5 main folders.

Abstracts: variables (color, font, margin, padding, etc), and some helpers and mixins functions
Base: typography, body/html..., animations, utilities
Components: button, general card, project card
Layouts: navbar, header, footer, grid, etc.
Pages: css specific to each of my five pages (home, portfolio, about, blog, contact)

Miscelleanous

I have created my own HTMLElement classes for the header, footer and cards for my portfolio projects

Lessons Learnt

I performed many refactoring throughout the developement of this site.

Refactoring the whole architecture gave me an insight into clean code and the DRY concept. I shall apply these principles in my future apps.

Still some effort on general Grid Systems, especially on how to have a consistent grid system throughout the whole site.
