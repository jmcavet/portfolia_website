Motives for developing a brand new Language App

While learning React and Redux back in 2020, I took a chance at applying my knowledge by developing a new Progressive Web Application (PWA) for learning foreign languages.


I used Supabase for my backend, giving me more time to focus on the frontend. While my previous language app (Linguappo) was not particularly solid in terms of design, I chose to consolidate my knowledge of UI & UX by designing every page using Figma.

How it works

Sign-up and Dashboard

If an account already exists, users can just log in with their email.
Otherwise, they must first signup, which creates an account in the Supabase database. Once valided, they can:

Create a new project by defining the learning language they want to learn as well as their mother tongue

Start adding some vocabulary for this specific project

View all their projects on the dashboard represented as cards or graphs (total number of words, categories, incomplete vocabulary, etc.)

Vocabulary and Tags

For a specific project, users can save their own items:

Enter some data (word, expression, verb, etc.) and its translation (directly or complete at a later date). If available, add some context and its translation for this specific item.

Any incomplete translation can be completed later.
Users can enter quickies in case they are in a hurry (e.g. listening to a conversation)

Create as many tags as needed in order to regroup the items, e.g. Adjective, Verb, Expression, Slang, etc.

Manage tags: edit or delete them. It will update automatically the database.

Game

The central part of the app. It enables users to:

Select 1 or a few corresponding projects for 1 specific language

Select the language you want to play with (learning or own language)

Select the method presenting the words (random or sorted by date) and the number of words to play with

Filter data according to various information: word types, categories, allocated score

Play the game by guessing the translation (blurred) and provide a grade (failed, neutral, passed)

Dictionary

For a specific project and language, users can search for 1 or multiple items. In particular, they are able to:

Search a specific item by its name

Sort the list of items by date

Filter data according to various information: word types, categories, allocated score, items complete or incomplete, favourites

Select a specific item and update its properties

Select 1 or multiple items and delete them

I use this app on a weekly basis to help me assimilate words, expressions, verbs that I need for my daily job. It helps me especially communicate more clearly during meetings and technical presentations.
At home, I take advantage of it to check any new word when the conversations turn into italian or german within the family :)
