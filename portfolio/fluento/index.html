Motivation for Developing a New Language Application

In 2020, while learning React and Redux, I decided to put my knowledge into practice by creating a Progressive Web Application (PWA) for learning foreign languages.

I built this application with a specific purpose in mind: reinforce words, expressions, and verbs that are essential for my daily work. It has been so far especially helpful for communicating clearly during meetings and technical presentations.

The goal of this project was threefold:

Create a practical application that I could use daily in any context

Develop web technology skills using a modern frontend framework, React

Gain solid experience in UI/UX design covering the process from concept to completion

For the backend, I chose Supabase, which allowed me to focus on the frontend experience. Unlike my previous language app (Linguappo) which lacked design consistency, I aimed to strengthen my UI&UX skills by designing every page in Figma.

How it works

Sign-up and Dashboard

Users with an existing account can log in directly using their email.
New users first sign up, which automatically creates their account in the Supabase database.
Once validated, they can:

Create new projects — Select the target language to learn and their native language

Add vocabulary — Enter words, translations, and contextual notes for each project

Explore the dashboard View all projects as cards or graphs showing key stats such as total words, categories, and incomplete items

Vocabulary and Tags

For each project, users can create and manage their own vocabulary items:

Add new entries — Enter a word, expression, or verb with its translation. If it’s not ready, complete it later. Optionally, include a context sentence and translation for better understanding

Complete translations later — Update incomplete items anytime, or add quick entries on the go — for example, when hearing new words in conversation

Organize with tags — Create custom tags (e.g., Adjective, Verb, Expression, Slang) to group and filter vocabulary

Manage tags easily — Edit or delete tags; all changes sync automatically with the database

Game

The heart of the application, where users review and test their vocabulary:

Select projects — Choose one or more projects for a specific language

Choose the mode — Play using either your learning or native language

Pick a method — Show words randomly or by date, and set how many to review

Filter your data — Focus on selected word types, categories, or scores

Play the game — Guess blurred translation and rate your answer as failed, neutral, or passed to track your progress

Dictionary

For each project and language, users can search, filter, and manage their saved items:

Search items — Find specific words or expressions by name

Sort by date — Organize the vocabulary list chronologically to track progress over time

Filter results — Narrow down items by word type, category, score, completion status, or favorites

Edit items — Select any entry to update its properties or correct information

Delete items — Choose one or several entries to remove them permanently from the project

Architecture

Summary

This application combines React, Redux, and React Router DOM with Supabase as backend.

It uses context-based state management for each major feature and a dedicated service layer for API communication. Routing is managed in the App.jsx file with protected and public routes, while React Query handles caching and data synchronization.

This architecture ensures a clear separation between logic, data, and presentation.

The main pillars

Router & Entry Point

The app is initialized in main.jsx, wrapped in BrowserRouter. Routes are defined in App.jsx, where a ProtectedRoute guards authenticated pages while keeping public routes like Login, Sign-Up, and Landing Page accessible.

Global Providers

The application is wrapped in several global providers: MainProvider for shared context, QueryClientProvider for caching and server state (via React Query), GlobalStyles for consistent UI, and Toaster for user notifications.

State Management

The app combines Redux for managing global state with React Context + Reducer for feature-specific logic. This hybrid setup ensures consistent data handling across the app while keeping each module isolated, scalable, and easy to maintain.

Service Layer

Modules such as apiAuth.js, apiCategory.js, and apiProject.js encapsulate all database interactions with Supabase, handling authentication and CRUD operations through a clean, reusable API layer.
