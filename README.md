# Jean-Marie Cavet - Personal Website

A personal website showcasing my web development projects, skills, and portfolio. Built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive design for mobile and desktop
- Project showcase with links to GitHub repos as well as the application themselves
- Interactive UI components

## Installation

1. Clone the repository:

git clone [Repo personal Website](https://github.com/jmcavet/portfolia_website.git)

## Deployment

The website is hosted on Vercel: [Jean-Marie Cavet Website](https://app.netlify.com/projects/jeanmariecavet/)

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- Figma for the UI/UX design
- d3.js visualization library
- Git & GitHub for version control
- Netlify for deployment
